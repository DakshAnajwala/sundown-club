# Sundown Club design system: proposal

Phase 2 of `docs/prompts/design-overhaul.md`. Status: **proposed, waiting on
the owner's sign-off (§9)**. Nothing in any app uses it yet. Each surface
switches over in Phase 5, after the React rebuild (Phase 3) reaches parity.

| What | Where |
|---|---|
| Source of truth | `packages/shared/design/tokens.js` (plain data, runs in node) |
| CSS variables for the DOM | `packages/shared/design/tokens.css`, generated by `npm run tokens` and never edited by hand |
| Live specimen | `/shared/design/specimen.html` on the built site (`npm run build && npm run serve`); screenshots in `screens/system/` |
| Checks | `node tools/design-check.mjs`, now part of `npm run check`: tokens.css is current, and 188 contrast pairs pass WCAG AA |
| Product context | `/PRODUCT.md` (written this phase) |
| The system as it ships today | `/DESIGN.md` (written this phase; replaced once this one is built) |

## 1. The idea

**North Star (proposed): "The Last Hour of Daylight".** The phrase is from
the hub's own manifesto.

The club is one evening. Everything is lit by a setting sun and then by a
lamp. The interface is the quiet part: one family of warm dark surfaces that
changes with the sky, one accent per game, and three typefaces with fixed
jobs. A result gets one moment in the game's colour and then steps aside.

It fixes the audit's system-level failures:

- **Four brands become one** (AUDIT #5).
- **The shared overlays stop wearing Blackjack's orange** (#5, #24).
- **Every allowed text pair is contrast-checked by a script** (#26).
- **Tokens stop being copied into each app** (#29).

## 2. Colour

**Ink never changes.** The same three inks are used on every surface, in every
sky and in every game, so contrast is proven once per surface:

| Token | Hex | Use | Lowest measured |
|---|---|---|---|
| `--ink-1` | `#f3e7d8` | Text, icons, the focus ring | 7.97:1 (glass over a white sky) |
| `--ink-2` | `#cdbcaa` | Supporting text, labels on glass | 5.26:1 (glass over a white sky) |
| `--ink-3` | `#a8988a` | Captions on solid surfaces only, never on glass | 5.22:1 (dusk s3) |

**Surfaces follow the sky.** There are four solid steps, from `--s0` (the page)
to `--s3` (hover and selected). They are tinted amber-brown at golden hour,
plum at dusk and violet-navy at night. A page or game sets
`data-sky="golden|dusk|night"`; games with a day cycle switch it as their sun
sets (`scene.phaseAt`).

**Glass is `--s1` at 80% with a 14px blur.** It is used only for panels that
float over a 3D scene, never as decoration. With "reduce transparency" turned
on, it becomes solid.

| Sky | s0 | s1 | s2 | s3 | Sun (the club's own accent) |
|---|---|---|---|---|---|
| Golden hour | `#120d0b` | `#1b1411` | `#261c18` | `#33261f` | `#f4ad6e` |
| Dusk | `#130c10` | `#1c1318` | `#281b22` | `#35242d` | `#ec9a80` |
| Night | `#0c0b13` | `#14121d` | `#1e1a29` | `#292436` | `#c8d0f4` (moon) |

**One accent per game.** These are your binding identity, unchanged. Setting
`data-game` swaps `--accent` and `--on-accent` (the text colour on the
accent):

| Game | Accent | Text on it | Contrast |
|---|---|---|---|
| Blackjack | `#f0a868` | `#1b1109` | 9.3:1 |
| Hold'em | `#d98a93` | `#1d0d10` | 7.2:1 |
| Video Poker | `#e8b860` | `#1b1306` | 10.0:1 |
| Parking Precision | `#8fe3cf` | `#08201a` | 11.4:1 |
| Night Drive | `#9aa6ff` | `#0e1030` | 8.2:1 |

- **The accent fills one control per screen.** That is the primary action;
  everything else stays ink on surface.
- **Screens that belong to no game use the sun as the accent.** These are the
  hub before a game is picked, the legal pages and the About section.
- **One mint.** Parking's three mints become one, `#8fe3cf`. The glowing bay
  keeps its own scene colour.

**Results** are quiet and readable on every surface, including glass over a
white sky:

- **Win:** sage `#a3d4b0`.
- **Lose:** clay `#eda08f` (4.64:1, the lowest pair in the system).
- **Push:** ash `#c9beb1`.

Never casino green. A natural or a jackpot uses the game's accent instead.

**Retired:**
- **Cream paper panels.** Their dark ink on light flipped the meaning of
  `--ink`.
- **Felt-teal buttons.**
- **The blue focus ring.**
- **Lab teal.**
- **The coloured selection glow** (see §5).

## 3. Type

Three faces, each with one job. All are already self-hosted:

- **Young Serif names things and marks moments.**
- **Schibsted Grotesk does the work.**
- **IBM Plex Mono sets every number a player compares, and every key.** It is
  never used as decoration.

Sizes are in rem, so they follow the player's text-size setting. Tracking
depends on the size.

| Role | Size | Leading | Tracking | Use |
|---|---|---|---|---|
| Display | 44 → 92px (fluid) | 1.0 | −0.015em | Game names, the hub hero |
| Headline | 26 → 34px | 1.1 | −0.01em | Section titles, dialog questions |
| Title | 20px | 1.2 | 0 | Tile and card names, coach titles |
| Lead | 18px | 1.55 | 0 | One per screen, max 44ch |
| Body | 15px | 1.5 | 0 | UI text, buttons at 600 |
| Caption | 13px | 1.4 | +0.005em | Help lines, small print |
| Label | 12px mono caps | 1.2 | +0.12em | Room names, column heads. **Never smaller than 12px** (fixes the 10px text the detector found) |
| Key | 12px mono 600 | 1 | 0 | Keycaps |
| Number | 20px mono, tabular | 1.1 | 0 | Chips, bets, scores, times |
| Figure | 28 → 40px mono 600 | 1.0 | −0.01em | A result worth a moment (+75, 96 / 100) |

**No eyebrow above a heading, and no section numbers ("01 · Cards").** The
heading carries its own weight. This changes copy on the hub (see §9).

## 4. Space, layout and shape

- **Spacing.** A 4px rhythm: 4, 8, 12, 16, 20, 24, 32, 40, 56, 80 (rem
  tokens `--space-1` to `--space-20`). The side gutter stays
  `clamp(16px, 4.5vw, 64px)`.
- **HUD panels** sit 16px from the window edge (`--hud-inset`).
- **The HUD band.** Every game keeps a 112px band clear at the bottom for its
  action bar (`--hud-band`). Cameras frame your cards and bet above it. This
  fixes Blackjack's covered cards and Hold'em's tiny hand (AUDIT #10).
- **Radii.** Ten radii collapse to four plus a pill:
  - key 4px;
  - control 10px;
  - surface 14px;
  - sheet 20px;
  - pill.
  
  A nested corner is the outer radius minus the padding between the two.

## 5. Depth

Depth comes from shadow and light, **never from a hard border**:

| Token | Meaning |
|---|---|
| `--edge` | A faint inner ring plus a brighter top edge, as if light catches the material |
| `--lift-1` / `--lift-2` / `--lift-3` | Soft, offset, semi-transparent shadows for controls / panels over 3D / dialogs. They grow with the surface |
| `--selected` | A 2px accent ring plus a neutral lift |
| `--focus-ring` | A two-tone ring (surface, then cream), visible on any fill including an accent button |
| `--scrim` | A 58% dim behind a modal |

**Change from the approved hub spec (needs your yes).** Today the selected
rail tile casts a glow in its game's colour (hub SPEC §4.4). The design
detector flags coloured glow as a stock "AI look". The proposal keeps the
accent ring and the lift but drops the glow. The selected tile still rises
and brightens its image.

## 6. Motion

These tokens follow Emil Kowalski's rules and Apple's *Designing Fluid
Interfaces*:

| Token | Value | Use |
|---|---|---|
| `--dur-press` | 120ms | `:active` press feedback, scale 0.97 |
| `--dur-quick` | 160ms | Hover, colour, tooltips, every exit |
| `--dur-ui` | 220ms | Dialogs and popovers entering (from scale 0.97 and an 8px rise, never from 0) |
| `--dur-sheet` | 320ms | Drawers: the garage, level select |
| `--dur-moment` | 600ms | A result worth a beat (rare) |
| `--dur-scene` | 900ms | Backdrop and sky crossfades (decorative, rare) |
| `--ease-out` | `cubic-bezier(.23,1,.32,1)` | Entering, responding |
| `--ease-in-out` | `cubic-bezier(.77,0,.175,1)` | Moving on screen |
| `--ease-sheet` | `cubic-bezier(.32,.72,0,1)` | Drawers and sheets |
| `--ease-colour` | `ease` | Hover and colour |

Springs (in JS for React Three Fiber and Motion) are critically damped by
default. The camera rig uses damping 1 and response 0.6. Bounce (0.2) is
allowed only after a gesture with momentum.

**Never animated:**
- anything the keyboard repeats: game hotkeys, holding cards, the hub rail's
  arrows. These state changes are instant, with press feedback only;
- numbers during play;
- focus rings;
- layout. Only transform, opacity, blur and clip-path move.

**Reduced motion.** `--move` becomes 0, so every travel distance is
multiplied away. Scales become 1. The long moments shorten to a 200ms
cross-fade. Colour and opacity still change, so state is never lost.

**Also covered:**
- **Reduced transparency:** glass becomes solid.
- **More contrast:** all ink goes to cream, and edges become visible.

## 7. The 3D palette

`tokens.js` also exports `scene`, the colours three.js uses:

- the nine day-cycle keys;
- rooms, lights and materials;
- felt;
- cards;
- the eight chip colours.

These are copied exactly from `packages/shared/lounge/`. The React Three Fiber
kit (Phase 3) reads them from here, so moving them there changes no pixel.
Parity is preserved.

## 8. How apps use it

- **Static pages** (until React):
  `<link rel="stylesheet" href="/shared/design/tokens.css">` and
  `import { games, scene } from '/shared/design/tokens.js'`.
- **Vite and React apps:** `import '@sundown/shared/design/tokens.css'` and
  `import { scene } from '@sundown/shared/design/tokens.js'`. Tailwind's theme
  (Phase 3) maps to the same CSS variables, so classes, components and scenes
  cannot drift apart.
- **Changing a token:** edit `tokens.js`, run `npm run tokens`, then run
  `npm run check`. The check fails if `tokens.css` is stale or any contrast
  pair drops below AA.

## 9. Waiting on the owner

The design-language question timed out unanswered, so items 1–3 are my
recommended defaults, not your answers:

1. **North Star: "The Last Hour of Daylight"** (alternatives: "The Lamplit
   Lounge", "The Evening Club").
2. **One dark surface family that shifts with the sky,** everywhere. This
   retires the card games' cream paper panels.
3. **Components: "quiet and tactile".** Small, soft and pressable; they step
   back until you need them. (Alternatives: "brass and wood, in-world";
   "precise and instrument-like".)
4. **Drop the coloured glow on the selected hub tile** (§5); keep the ring
   and the lift.
5. **The sun as the club's own accent** on screens that belong to no game.
6. **No eyebrows above headings and no section numbers.** The hub's "01 ·
   Cards", "In the workshop", "Your evening" and "Who runs the club" labels
   go. Their words fold into the headings, or go if the heading already says
   it.

waiting on your yes before converting anything.
