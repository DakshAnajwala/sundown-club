# Sundown Club brand

The club's logo is the **pendant lamp**: a lamp hanging over a table, throwing
warm light down at the start of the evening ("The lamp stays on"). Chosen by
the owner on 2 Oct 2026 from five options, kept in `options/`.

## Files

| File | Use |
|---|---|
| `logo/mark.svg` | Master logo, on its dark tile. Every other file is made from it. |
| `logo/mark-light.svg` | The lamp alone, in dark ink, for light backgrounds. |
| `logo/mark-400.png` | LinkedIn company page logo (400 × 400). |
| `logo/mark-1024.png` | Large square logo, for anywhere that wants a big image. |
| `logo/cover-1128x191.png`, `logo/cover-2256x382.png` | LinkedIn cover banner (1× and a sharper 2×). Upload the 2× one if LinkedIn accepts it. |
| `logo/lockup-dark.png`, `logo/lockup-light.png` | Logo and name together on a transparent background, for dark and light pages. |
| `options/` | The five options the lamp was chosen from (A Horizon, B Last light, C Card at dusk, D Pendant lamp, E S and reflection). |

The site's tab icon (`apps/hub/favicon.svg`) and home-screen icon
(`apps/hub/apple-touch-icon.png`) are the same lamp.

To regenerate every PNG and the site icons after changing `logo/mark.svg` or
`logo/mark-light.svg`:

```
npm install --no-save puppeteer-core
node tools/brand-export.mjs
```

## Colours

| Name | Hex | Where |
|---|---|---|
| Night | `#15100e` | Logo tile |
| Lamp shade (cream) | `#f3e7d8` | Shade and cord; the name on dark |
| Bulb | `#ffd49a` | The bulb |
| Glow (amber) | `#f0a868` | The light and the table edge; the club's own accent |
| Ink | `#1b1411` | The name and the lamp on light backgrounds |

## Type

The name is set in lower case in **Young Serif**. The tagline uses
**Schibsted Grotesk**, and addresses use **IBM Plex Mono**. All three are
under the SIL Open Font License, which allows their use in a logo and in
commercial work; the fonts themselves are not sold or given away here.
